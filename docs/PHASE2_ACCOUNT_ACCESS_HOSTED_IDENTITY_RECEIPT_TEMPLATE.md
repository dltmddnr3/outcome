## 기록 금지

다음 값은 이 문서, Git, Gate 증거, 로그, 스크린샷 또는 전달 메시지에 기록하지 않는다.

- 이메일, 전화번호, 실명, 사용자 사진
- 클러크 주체·사용자·애플리케이션·인스턴스 식별자
- 공개키·비밀키의 실제 값, OAuth 클라이언트 값
- 세션 ID, 세션 토큰, 액세스·갱신 토큰, 쿠키
- 이메일 인증 코드, OAuth 인증 코드와 콜백 질의 문자열
- 애플 개인 키, 수파베이스 키, 데이터베이스 연결 문자열
- 로컬 절대 경로, 원시 Gate 증거, 비공개 프로젝트 내용

위 항목이 노출되면 즉시 기록을 중단하고 노출 표면을 폐기한 뒤 자격증명 철회·회전 여부를 별도 승인 경계에서 판단한다.
